HOW TO USE EACH FILE
---------------------
Each file has clearly labelled sections matching Shopify's blog post fields:
- TITLE                -> Shopify "Title" field
- URL HANDLE           -> Shopify "URL and handle" (under the title, click "Edit website SEO")
- SEO TITLE             -> same SEO panel, "Page title"
- META DESCRIPTION      -> same SEO panel, "Meta description"
- EXCERPT               -> Shopify "Excerpt" field (right-hand sidebar)
- AUTHOR                -> Shopify "Author" field
- FEATURED IMAGE        -> not yet supplied for any of the 7 posts — see below
- BODY HTML             -> paste into the article body. In Shopify's editor, click the
                           "<>" (Show HTML) button in the toolbar, paste the whole HTML
                           block in, then toggle back to rich text to confirm it renders
                           correctly before saving.
